# Tokens

Propellant components render under a `[data-propellant]` boundary and paint with semantic
tokens named by role: label, fill, separator and grouped background. Use the
**Theme** toolbar to compare light, dark and the system setting. The Propellant site lists every
token with its values and measures contrast live.

<div data-propellant style={{ display: 'grid', gap: 32 }}>

## Surfaces

<div style={{ display: 'flex', gap: 12, flexWrap: 'wrap' }}>
  {[
    ['--bg-grouped', 'Page'],
