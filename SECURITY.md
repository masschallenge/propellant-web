# Security

Propellant is a design system: styles, components and documentation. It holds no user data,
passwords or keys. Problems can still happen, for example a component that lets unsafe content
through, so we take reports seriously.

## Reporting a problem

Please do not report a security problem in a public issue, where others could misuse it before it
is fixed.

Report it privately instead:

1. Open the repository's **Security** tab on GitHub.
2. Click **Report a vulnerability**.
3. Describe the problem, the affected version and, if you can, the steps to reproduce it.

Only the people who maintain Propellant can see the report. We will confirm we received it, keep
you updated while we work on a fix, and credit you in the release notes if you would like.

## Supported versions

We fix security problems in the latest release. If you are on an older version, update to the
latest one to get the fix.
